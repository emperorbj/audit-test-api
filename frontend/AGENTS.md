# AGENTS.md: Audit Agent frontend

## Design system
Before any UI work, read `design-kit/README.md`, then `design-kit/PROJECT-NOTES.md`.
- Follow approved kit records. Label anything marked CANDIDATE as such in your summary.
- Use semantic colour tokens only (`--primary`, `--background`, `--border`, `--ring`…). No hard-coded hex values.
- Do not edit files in `design-kit/` except `PROJECT-NOTES.md`. The rest is generated from the `fa-design-system` repo.
- Go through `design-kit/checklist.md` before finishing UI work. List any new reusable component or pattern as a proposal for the design repo.
